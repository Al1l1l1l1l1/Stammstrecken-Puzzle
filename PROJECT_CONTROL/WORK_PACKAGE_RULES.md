# Arbeitspakete
Ein Agent übernimmt ein zusammenhängendes Paket von der Umsetzung bis zur Integration.
Maßgeblich sind der aktuelle Auftrag, seine Produktquellen und die vereinbarten Abnahmekriterien.
Nachbesserungen gehören zum Paket. Änderungen außerhalb des Auftrags klärt der Agent mit dem Owner.
Sind die Pflichtprüfungen grün, integriert der Agent auf den im Auftrag freigegebenen Branch.
